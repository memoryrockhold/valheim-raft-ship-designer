## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Hull Planner** | Design your raft hull shape and dimensions on a grid canvas |
| **Mast Layout** | Plan mast positions and sail configuration for your vessel |
| **Material Calc** | Calculate total wood, iron and special materials for your design |
| **Cargo Estimate** | Estimate cargo capacity based on your planned hull dimensions |
